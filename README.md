# 나를 기억하는 웹 비서

**사용자 PC에 Python·프로그램 설치 없이, Chrome/Edge에서 접속하는 웹 버전**입니다.

## 사용 흐름

1. 웹사이트에 접속합니다.
2. 화면 선택 → 분석 → 맞음 또는 교정 기억하기.
3. 같은 적용 상황에서 분석하면 관련 교정을 다시 사용합니다.
4. 저장된 기억에서 수정·삭제하거나 백업 파일을 받을 수 있습니다.

AI가 연결되지 않은 사이트는 **브라우저 데모**로 표시됩니다. 화면 선택 없이 본문만 붙여넣어 교정 흐름을 시험할 수 있습니다. 데모는 이미지 이해·AI 요약을 하지 않으며, 교정을 보여주기만 합니다. 실제 API 모드에서는 모델 입력에 교정을 제공하지만, 모델이 정확히 따르는지는 별도 평가가 필요합니다.

## 어디에서 처리하나요?

| 기능 | 위치 |
| --- | --- |
| 공유 화면 선택·해시 계산·이미지 축소 | 사용자 PC의 브라우저 |
| 교정 기억 저장·검색·분석 단계 기록 | 브라우저 IndexedDB |
| 실제 이미지 이해·요약 | 선택한 외부 AI API (서버가 중계) |
| 선택적 교정 동기화 | 서버 SQLite |

원본 화면은 브라우저나 서버에 영구 저장하지 않습니다. 실제 AI 분석에는 화면·본문·관련 교정이 서버와 AI 제공자에게 전송됩니다. 답변·분석 기록은 브라우저에만 저장하고, 서버에는 동기화를 켠 교정과 사용량 집계만 저장합니다. AI 제공자의 보관 정책은 별도입니다. 이 버전은 브라우저 안에서 AI 모델을 실행하거나 모델을 재학습하지 않습니다.

기억은 적용 상황 이름이 정확히 같은 최근 교정 5개를 검색합니다. 서버 동기화는 기본 꺼짐입니다. 로그인 없이 브라우저별 임의 비밀키로 저장소를 분리하는 시험 버전이며, 정식 계정/비밀번호 복구 기능은 없습니다. 다른 PC로 옮길 때는 기억 백업·가져오기를 사용하세요. 비밀키는 백업에 포함하지 않으며 새 PC에서는 별도 서버 저장소를 사용합니다. 브라우저 데이터를 지우기 전에 서버 사본을 삭제하거나 백업하세요. 비밀키를 잃으면 과거 서버 사본을 관리할 수 없습니다.

기억 삭제는 다음 분석부터 제외합니다. 과거 단계 기록에 남은 교정 사본은 `이 브라우저의 분석 기록 삭제`로 삭제합니다. 서버 사본 전체 삭제는 동기화를 끄고 서버 데이터도 지우며, 로컬 기억은 유지합니다. 서버/브라우저 DB는 앱 자체에서 암호화하지 않습니다. 사이트 관리자나 같은 브라우저 프로필 사용자를 신뢰할 수 있는 범위에서 시험하세요.

## 정적 웹 배포: GitHub Pages (무료 데모)

웹 파일은 `docs/`에 있습니다. `.github/workflows/pages.yml`은 테스트 후 해당 파일만 Pages에 배포합니다. 키·DB·Python 코드는 웹 배포 파일에 포함하지 않습니다.

저장소 소유자가 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 한 번 선택해야 합니다. 이후 **Actions → Publish browser app → Run workflow**를 실행하면 배포합니다. GitHub 계정 정책이나 저장소 공개 여부에 따라 Pages 사용 가능 여부가 다를 수 있습니다. Actions 실행 결과의 배포 주소를 사용하세요. 설정 전에는 주소가 동작한다고 가정하지 마세요.

정적 웹만 배포하면 실제 AI API와 서버 동기화는 연결되지 않습니다. 데모는 전부 사용자 브라우저에서 작동하고 API 비용이 없습니다.

## 실제 AI + 교정 서버: 선택적 배포

동일 출처에서 FastAPI가 웹 파일과 `/api`를 함께 제공합니다. `render.yaml`은 Render 배포 예제입니다. **유료 Starter 서버·영구 디스크 예제이며 자동으로 구매하거나 배포하지 않았습니다.** 실제 운영에는 인증·가입 제한·개인정보 처리방침·데이터 삭제/보관 정책·비용 모니터링을 추가해야 합니다. 현재는 제한된 시험용입니다.

서버 환경 변수에만 설정하세요. 키는 Git·브라우저·채팅에 넣지 않습니다.

- `ASSISTANT_API_KEY`: 이미지 입력 지원 OpenAI 호환 API의 키
- `ASSISTANT_MODEL`: 선택한 모델 ID
- `ASSISTANT_API_BASE`: 기본 `https://api.openai.com/v1`, HTTPS 필요
- `ASSISTANT_ALLOWED_HOSTS`: 실제 서비스 호스트 이름 (쉼표로 구분, URL/경로 제외)
- `ASSISTANT_DB`: 영구 디스크의 SQLite 경로
- `ASSISTANT_DAILY_LIMIT`: 서버 전체 일일 분석 시도 한도, 기본 50
- `ASSISTANT_USER_DAILY_LIMIT`: 브라우저별 일일 시도 한도, 기본 10

실패 요청도 한도에 포함하며 자동 재시도는 없습니다. 브라우저 토큰을 새로 만들면 개인 한도를 우회할 수 있지만 서버 전체 한도는 유지됩니다. 횟수 제한은 금액 제한이 아니므로 AI 제공자 콘솔에서도 지출 한도를 설정하세요. 화면 분석 요청당 최대 출력 1,200토큰입니다. 서버 키가 없으면 실제 AI 요청을 거부하고 웹은 명시적 데모로 동작합니다. 공개 AI 서비스 운영 전 정식 로그인과 악용 방지가 필요합니다.

## 개발자 검증

일반 사용자는 아래 명령이 필요 없습니다. 개발자는 저장소 루트에서:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
node --test tests/core.test.mjs
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8001
```

Playwright와 Chromium이 있는 개발 환경에서 별도 터미널로:

```bash
node tests/browser_smoke.cjs
```

Windows에서 기존처럼 로컬 시험도 가능합니다. `start-windows.cmd`는 유지합니다. 이전 버전의 `data/assistant.db`를 새 웹 저장소로 자동 이전하지는 않습니다. 이전 교정은 새 웹 화면에 입력하거나 백업 형식으로 가져와야 합니다. 이전 DB 파일은 수정하지 않습니다.

검증 범위: 서버의 교정 동기화·사용자 분리·삭제 우선 병합, API 요청·오류·횟수 제한, 화면/본문 미저장, 호스트/출처/크기 보호, 브라우저에서 기억 재사용·새로고침 유지·편집·삭제, 서버 없는 정적 호스트 동작. 실제 Windows 화면 공유·실제 비전 API 품질·외부 배포 주소는 별도 검증 대상입니다.

화면 복사 직전 동일 공유 세션·동일 픽셀·5분 미만을 다시 확인합니다. 동영상/애니메이션도 화면 변경으로 감지합니다. 공유 세션 ID는 OS 창 ID가 아니며 검사 후 화면이 바뀔 수도 있습니다. 이 검사를 자동 클릭/송금 등의 안전 근거로 사용하지 마세요. 자동 PC 조작은 제공하지 않습니다.

오픈소스: FastAPI(MIT), Uvicorn(BSD-3-Clause), HTTPX(BSD-3-Clause), Python SQLite, 브라우저 표준 API를 활용합니다. 단계 기록의 판단 요약은 모델의 비공개 내부 추론이 아닙니다. 화면 이해·답변 생성은 한 API 요청이므로 오류 원인을 완전히 독립적으로 분리할 수는 없습니다.
