교정하는 화면 비서

웹페이지 요약부터, 내가 고친 내용을 다음 답변까지.

1. 화면과 적용 상황

읽고 싶은 브라우저 탭을 선택하세요. API 모드에서는 화면·본문·관련 교정이 설정한 AI 제공자에게 전송됩니다. 민감한 화면은 공유하지 마세요.

2. 설명과 다음 행동

분석 결과가 여기에 표시됩니다.

공유 세션·화면 픽셀 변경 시 중단합니다. 자동 클릭·입력은 지원하지 않습니다.

3. 단계별 기록

입력·출력·판단 요약·실패 유형입니다. 모델 내부 추론 기록은 아닙니다.



4. 저장된 기억
삭제하면 다음 분석부터 사용하지 않습니다. 과거 기록의 사본은 위의 전체 삭제로 지울 수 있습니다.
